# React Native Counter App

A simple React Native app built with Expo featuring a "Hello World" text and an interactive counter.

## Features

- Hello World text display
- Counter with increment, decrement, and reset buttons
- Clean and modern UI design

## Getting Started

### Prerequisites

- Node.js (v14 or newer)
- npm or yarn
- Expo CLI (optional, but recommended)

### Installation

1. Navigate to the react_native_app directory:
```bash
cd react_native_app
```

2. Install dependencies:
```bash
npm install
```

### Running the App

Start the development server:
```bash
npm start
```

This will open Expo DevTools in your browser. From there you can:
- Press `w` to open in web browser
- Scan the QR code with Expo Go app (iOS/Android)
- Press `a` to open Android emulator
- Press `i` to open iOS simulator

### Available Scripts

- `npm start` - Start the Expo development server
- `npm run android` - Run on Android device/emulator
- `npm run ios` - Run on iOS simulator
- `npm run web` - Run in web browser

## App Structure

- `App.js` - Main application component with counter logic
- `package.json` - Project dependencies and scripts
- `app.json` - Expo configuration
- `babel.config.js` - Babel configuration for Expo
